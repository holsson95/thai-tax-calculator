Project: MyThaiTaxes

Goal:
Improve MyThaiTaxes into a high-quality Thailand personal tax
calculation and education platform.

Primary goals:
1. Make tax calculations accurate and transparent.
2. Make the calculator the core product.
3. Add original educational value rather than generic AI-generated content.
4. Improve trust, transparency, UX and maintainability.
5. Prepare the site for AdSense review.

IMPORTANT TAX RULE:
Never invent, assume, or update Thai tax rules from model knowledge alone.

For every tax-related rule:
- Identify the source.
- Record the applicable tax year.
- Record any conditions/limitations.
- Preserve the source URL/document.
- Do not state uncertain tax interpretations as fact.

CONTENT RULE:
Do not generate generic SEO articles simply to increase page count.

New content should add at least one of:
- original calculation
- worked example
- comparison
- interactive tool
- original explanation
- useful table
- methodology
- clearly documented interpretation
- practical decision guidance

TECHNICAL RULE:
Do not change the existing tax calculation engine unless:
- the current behavior is documented,
- the proposed behavior is justified,
- tests are added,
- the change is explicitly approved.

Before modifying core tax calculations:
1. Inspect the existing implementation.
2. Identify all affected files/functions.
3. Create/update tests.
4. Explain the proposed change.
